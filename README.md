# YunGet（云取）

> 网盘分享链接解析与高速下载的 Android 应用。粘贴分享链接，就能浏览分享内容并直接下载文件。
>
> **本项目是 [CYQawa/YunX（云析）](https://github.com/CYQawa/YunX) 的二次开发版本**，在其协议与架构基础上**重写并升级了多线程下载引擎**。遵循 GNU AGPL-3.0 协议开源。

## 功能

- **分享链接解析**：识别夸克 / UC / 迅雷 / 百度 / 139 / 123 的分享链接，自动匹配提取码
- **高速下载**：自适应多线程分片并发 + 断点续传，HTTP/2 连接复用
- **临时转存清理**：百度/迅雷取链后清理；夸克保留到下载完成或删除任务后清理
- **登录**：夸克 / UC / 百度 / 139 使用 WebView Cookie；迅雷使用密码/短信；123 使用账号密码换取 JWT
- **认证备份**：使用用户口令派生密钥，以 AES-GCM 加密 Cookie/JWT 备份文件
- **剪贴板识别**：复制分享链接后回到应用，提示一键粘贴解析
- **桌面图标切换**：内置「下载图标（默认）/ 经典图标 / 云 X 图标」三套，主题与外观页一键切换

## 多线程升级（本版本核心改动）

上游采用「主池 70% 等分 + 弹性区 30% 中点劈分」的两阶段分片模型。本版本在 `AdaptiveDownloadEngine` 中重写为一套**自适应引擎**，共四项升级：

1. **工作窃取调度（work-stealing）**：不再区分主池 / 弹性区，整文件由单一顺序游标按块发放，任一空闲线程立即领取字节相邻的下一块；失败 / 需细分的块回投共享 retry 双端队列被任意空闲线程窃取补下——消除上游「主池耗尽瞬间全部线程涌入弹性区、并发形态突变」导致的中后段掉速与尾部并发塌缩。
2. **动态并发调节（AIMD）**：监督协程周期性采样总吞吐，吞吐上升则 +1 线程探测（加性增），吞吐下降 / 出错则 -1 回退；遇服务器忽略 Range / 限流立即乘性收缩（减半）。线程增减通过对固定容量信号量「寄存 / 释放」许可实现，真实生效且不越界。
3. **自适应分块**：块大小随实测单连接吞吐动态调整，使单块下载耗时贴近目标值（慢连接自动用小块、快连接用大块），文件尾部自动收敛块大小，避免「最后一个大块单线程收尾」的长尾。
4. **连接复用 / HTTP2**：复用下载专用 OkHttp 客户端（HTTP/2 多路复用 + 大连接池 keep-alive），错峰建连平摊 TCP/TLS 握手突发。

引擎结局与上游保持兼容语义：`Completed`（合并）/ `NeedSingleStreamFallback`（服务器忽略 Range 时回退单流整文件）/ `Failed`（回退单流兜底）。

## 使用

1. 在「网盘」页登录需要用的网盘账号
2. 在「解析」页粘贴分享链接（可带提取码）
3. 浏览分享内容，点击文件获取下载直链
4. 「下载」页查看进度，支持暂停 / 继续 / 删除 / 打开

## 技术栈

- Kotlin
- Jetpack Compose + Material 3
- Room（凭证与下载任务持久化）
- OkHttp（网络请求 + 分片下载，HTTP/2）
- KSP

## 构建

要求：minSdk 23，targetSdk 34，JDK 17+。

```bash
git clone https://github.com/jiayuxuan123/YunGet.git
cd YunGet
# 配置 local.properties 指向 Android SDK：sdk.dir=/path/to/Android/sdk
./gradlew :app:assembleRelease
```

用 Android Studio 打开项目直接构建即可。国内网络可将 Gradle 与依赖仓库指向镜像（见 `gradle/wrapper/gradle-wrapper.properties` 与 `settings.gradle.kts`）。

## 关于协议逆向
