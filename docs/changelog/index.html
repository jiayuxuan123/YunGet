重要修复 · 修正两个开关同时打开时，下载完成的文件可能是坏的 「下载中预先合并」和「收尾托管」是引擎高级参数里的两项。两者同时开启时，同一个文件区间会被两个不同的请求先后写入。如果两个请求恰好落到不同服务器，后写的内容会覆盖先写的。 表现是：文件大小正确，但内容损坏，且下载过程中不会报任何错。 现在只要「收尾托管」开着，就会自动停用「预先合并」。 · 修正「HTTP 版本策略」选“自动”却实际走 HTTP/2 「HTTP 版本策略」默认就是“自动”，因此程序无法区分“你明确选了自动”和“你没设置过”。它只能用另一个开关——「强制 HTTP/1.1」——来决定，结果是你把这个开关关掉后，策略显示“自动”，实际生效的却是“允许 HTTP/2”。 HTTP/2 会把多个分片挤进同一条连接，多线程反而可能完全没有加速。 现在“自动”就是自动，不再被其他开关…
