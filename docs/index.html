三步拿到文件

没有账号体系、没有中转服务器：链接在手机上被解析，直链直接交给下载引擎。

粘贴链接 分享文案整段粘进来也行，应用会自己挑出链接与提取码。

选要下的文件 解析后能浏览目录、多选、按文件夹批量入队。

下载 分片并发、断点续传；锁屏也能接着下。

剪贴板识别 复制一条分享链接再回到应用，解析页会自动提示粘贴，不用手动找输入框。

多任务并行 默认同时下载三个任务，并发数可在设置里调；每个任务内部再分片并发。

它把文件切成段，同时下

服务器支持 Range 时，文件被切成不等长的分片并发拉取；慢的那片不会拖住整体。这件事 1857 年就有人做过 —— 大西洋海底电报线也是一条线切成几段接力。

分片并发 按 HTTP Range 并行拉取；服务器不支持时自动回退单流。

动态分块 + 工作窃取 慢连接不拖垮整体，消除最后一片单线程收尾的长尾。

断点续传 分片状态落盘，暂停后按真实进度接着下。

并发会自己收敛 并发升高而总吞吐不再提升时自动退回较低档位，不会出现「线程数拉满反而更慢」。

下载引擎是 TurboDL —— 一个纯 Kotlin/JVM 的多线程下载引擎，当前内置版本 0.3.0.0；它也可以被别的应用直接复用。

你的 Cookie 不离开这台手机

网盘登录凭据用系统密钥库加密后存在应用私有目录；解析与取直链都在本机完成，没有任何中转服务器经手你的账号。

系统密钥库加密 改锁屏密码或换设备会让密钥失效，那时应用会明确告诉你需要重新登录。

不出网 凭证只发给对应网盘的官方域名；应用不收集、不上报。

可导出备份 换手机时用自设密码加密导出，不依赖云端。

网盘接口变了，不用等应用更新

解析逻辑可以做进插件：装一个、启用，立即生效；网盘改接口时更新插件即可，不用等应用发版。

跑在沙箱里 插件是 JavaScript，只能通过宿主开放的接口访问网络与存储，越界调用会被拒绝并留下日志。

装上就生效 沙箱可以整体重建，所以插件启用、更新都不需要重启应用。

校验后才安装 每个版本都验 SHA-256 与签名；密钥被吊销的发布者即使签名有效也会被拒绝。

坏了能回退 更新失败自动回退上一可用版本；内置实现始终保留作兜底。
