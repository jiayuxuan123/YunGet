一条路线，五个明确站点

从输入到文件在本地落盘，每一步都有边界。平台需要登录时，应用会停在对应的登录步骤，而不是绕开权限。

  1. 01
    粘贴或分享进入入口

    剪贴板里有可识别链接时，解析页会提示粘贴；也可以手动输入整段分享文案。

  2. 02
    完成必要的平台登录按需

    在应用内打开对应平台的登录流程。凭证保存在本机，之后请求发往该网盘。

  3. 03
    浏览并选择文件选择

    分享可能是文件夹。解析成功后可逐层浏览、按文件或多选入队。

  4. 04
    交给 TurboDL执行

    HTTP、HTTPS 与网盘直链进入同一套下载流程，支持暂停、续传和失败重试。

  5. 05
    写入本地目录到站

    默认保存到公共 Download 目录；自定义目录受 Android 存储权限约束。

数据边界写清楚

这里只写代码与隐私说明能核对的范围，不把泛化保证当成验证结果。

解析路径

分享解析、文件选择和直链获取由设备上的应用发起；没有 YunGet 文件中转服务器。

凭证加密

网盘 Cookie、token 等凭证使用 AES-256-GCM 加密，密钥由 Android Keystore 生成且不可导出。

仍然需要注意

下载任务的请求头在应用数据库中以明文保存；导出日志也可能包含带签名的临时直链。

常见问题

内容默认展开遵循浏览器原生行为；没有 JavaScript 也能阅读。

要登录吗？

取决于网盘、分享链接和平台当前策略。完整目录浏览与直链提取可能需要登录；以平台当时的要求为准，应用会停在对应的登录步骤。

解析和下载会经过 YunGet 的中转服务器吗？

不会。YunGet 不运营网盘文件中转服务。解析、取直链和下载路径都在设备上的应用内执行，网络请求发往对应网盘与文件地址。

账号凭证放在哪里？

网盘凭证保存在应用数据库中，使用 Android Keystore 生成、不可导出的密钥加密。下载任务的请求头不在同一加密范围内，具体边界见隐私说明。

应该下载哪个 APK？

不确定时选通用包 <code>0-YunGet-2.7.28-universal.apk</code>。它兼容现有更新器；知道设备架构时，也可以选更小的 ABI 专用包。

插件能做什么？

Android 版目前只运行 JavaScript 插件，原生插件已停用。插件负责分享识别、解析和取直链，下载仍由 TurboDL 执行；手动导入的脚本会标为未验证。
