安装前后还可能需要什么

这些设置不影响 APK 真伪，但会影响下载的保存位置与后台行为。

Android 11 及以上

默认 Download 目录无需额外授权；改到其他公共目录时，系统可能要求“所有文件访问”。

后台下载

长任务需要通知、前台服务与保持唤醒；系统省电策略仍可能中断任务。

更新

应用检查更新读取 GitHub Release；同签名版本可覆盖安装。

安全边界

只从本页列出的 Release 附件下载，并核对 SHA-256。签名摘要不能替代对文件来源的核对。
