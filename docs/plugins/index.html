安装插件的两条路

优先从应用内插件市场安装；手动导入的文件不会被包装成“已验证”。

应用内插件市场

打开“插件 → 插件市场”，添加来源 https://raw.githubusercontent.com/jiayuxuan123/YunGet-Plugins/main/plugins.json，查看权限和信任等级后安装。已安装插件可以检查更新与卸载。

手动导入 未验证

从本地选择 .js 文件或粘贴脚本。手动导入没有来源签名链，必须视为未验证代码；安装前应自己阅读脚本与权限声明。

信任等级阅读方式

等级描述来源与签名，不描述脚本行为是否安全，也不代替代码审阅。

等级成立条件界面表现仍需判断
官方来源是官方源，且签名密钥与该源匹配。显示官方标记仍需查看权限与脚本行为
已验证用户添加的源，但清单签名与来源密钥可以核对。显示已验证标记仍需自行判断来源
社区用户添加、仍带签名信息的源。显示社区标记不等同官方审核
未验证没有可核对的签名或密钥，例如手动导入的脚本。明确警示执行前应审阅代码

能力边界

插件是解析器，不是第二个下载引擎，也不是远端代理。

可以

识别分享、拼接请求、读取网盘页面或 API 响应、返回结构化下载信息。

不可以

接管 TurboDL 的分片下载，或把应用伪装成网盘文件中转服务。

签名验证

可以证明脚本字节与某个密钥发布者一致；它不能证明作者可信或代码没有恶意。

网络权限

脚本的 http 权限意味着它可以把请求发往声明允许的目标；安装前要读权限。
