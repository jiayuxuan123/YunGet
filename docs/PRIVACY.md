# 隐私说明

这是一款以本地解析和下载为主的手机应用。下载与网盘操作不经过云取自己的中转服务器；
社区反馈和可关闭的匿名使用统计使用 Cloudflare Worker。下面逐项列出它什么时候联网、
数据存在哪里、哪些数据会汇总，以及哪些事情它从来不做。

## 它会联网的时候

| 什么时候 | 去哪里 |
|---|---|
| 解析分享链接、浏览目录、取直链、下载 | 对应网盘的官方接口与 CDN 地址 |
| 检查更新 | `api.github.com` 上本仓库的 Release 列表 |
| 导入 Gopeed 内核 | `api.github.com` 上上游内核仓库的 Release；或你选的镜像、网盘通道 |
| 浏览 GitHub 上的分享 | `api.github.com`、`raw.githubusercontent.com` |
| 下载 GitHub 上的文件 | 直连，或可配置的加速镜像 |
| 查看公告、进入社区、提交反馈 | `community.yunget.yunl.us.ci` |
| 发送匿名使用统计（默认询问，可关闭） | `community.yunget.yunl.us.ci` |
| 你自己粘贴的链接 | 你就让它去哪里 |

用 DoH 的时候，域名解析请求会发往你选定的那家公共解析服务（阿里、腾讯、Google、Cloudflare 之一）。

匿名统计关闭后不会发送统计请求；社区公告请求只用于读取公告。

## 它不做的事

- **不会静默开始统计**。2.7.31 起首次展示匿名统计说明；选择关闭后不发送事件，并清空本地待发送队列。
- **没有广告，也没有广告 SDK。**
- **没有崩溃上报**。崩溃报告只写在设备本地，可以在应用里查看、复制、分享 —— 但不会自动发给任何人。
- **不上传日志**。导出日志只有"分享到其他应用"和"保存到下载目录"两条路，都需要你手动操作。
- **不把网盘凭证发给对应网盘之外的任何地方。** Cookie 只出现在对网盘接口和网盘直链的请求里。

## 匿名使用统计

用途是判断哪些网盘、下载引擎或功能更需要优先修复。首次说明页可以选择“允许匿名统计”或
“关闭统计并继续”；之后可在“设置 → 关于与更新 → 匿名使用统计”随时修改。

- 会发送：事件名称、应用版本、Android API 级别、ABI、网盘来源类别、下载引擎、失败类别、下载/处理/保存阶段、可取得的最近 HTTP 错误码，以及粗粒度的文件大小和耗时区间。
- 不会发送：分享链接、文件名、账号昵称、网盘 Cookie/token、二维码内容、下载地址、IP 地址、精确文件大小或精确耗时。
- 匿名安装标识：客户端生成随机 UUID；服务端只保存使用 Worker 密钥计算出的 HMAC 摘要，用于去重，不保存原始 UUID。
- 保留期限：匿名事件最多保留 180 天，过期后由定时任务删除。
- 关闭时会清空设备上的待发送统计队列；已经汇总的历史事件不会因关闭而追溯到个人。

## 数据存在哪里

| 内容 | 位置 | 是否加密 |
|---|---|---|
| 网盘凭证（Cookie、token 等） | 应用数据库，按平台分表 | **加密**，见下节 |
| 下载任务与进度 | 应用数据库 | 否（其中请求头一项见下面的说明） |
| 下载任务的请求头 | 应用数据库 | **否** —— 这里存的 `Cookie`、`Referer`、`User-Agent` 是明文 |
| GitHub Token（如果你填了） | 应用设置（SharedPreferences） | 加密，用同一套密钥 |
| 诊断日志 | 应用私有目录，上限 1&nbsp;MB，写满后自动截半 | 否 |
| 崩溃报告 | 应用私有目录 | 否 |
| 下载的分片与临时文件 | 应用私有缓存目录 | 否 |
| Gopeed 内核 | 应用私有目录 | 否 |

关于那个明文项，值得直说：应用数据库本身受 Android 的应用沙箱保护（别的应用读不到，
卸载会一并删除），但设备被 root、或者有人能直接拿到这台设备的数据库文件时，
里面的 Cookie 是可以被读出来的，而 Cookie 等价于登录状态。
介意的话，别把设备交给别人，也别用被 root 的设备。

## 凭证是怎么加密的

- 算法 **AES-256-GCM**（128 位认证标签），密钥由 **Android Keystore** 生成，**不可导出**。
- 每条凭证在加密时都带一个用途标识（AAD，例如"夸克 Cookie""迅雷 refreshToken"），
  用它把一条字段的密文搬到另一条字段上是解不开的。
- 密钥**刻意没有**绑定"使用前必须验证指纹/锁屏密码"。这样做牺牲了一点强度，
  换来的是不会因为用户改了锁屏密码就让所有凭证一起失效。
- 密钥万一真的失效（例如系统层面重置了安全凭证），应用会清掉读不出来的那部分数据并提示重新登录，
  不会反复报错卡住。

## 导出认证备份时

「导出网盘认证」会生成一个 `.yunget` 文件，里面的内容**强制加密**：

- 你设的口令经 **PBKDF2-HMAC-SHA256**（随机 16 字节盐、210000 次迭代）派生密钥，
  再用 **AES-GCM** 加密。口令至少 8 位。
- 文件会保存到公共下载目录 —— 也就是说，**任何能读到这个目录的应用都可能拿到它**。
  传给别人之后记得删掉。
- 口令**没有找回途径**，也没有后门。忘了就只能重新登录每个网盘。
- 备份里包含蓝奏云的账号名与密码（那个平台的登录方式决定了这一点），所以这个文件值得当作密码对待。

## 导出日志时

日志里可能含有下载直链（网盘直链自带签名，等于一把有时效的钥匙）、文件名、
以及部分请求信息。代码里对 `Cookie`、`Authorization`、`token`、`sign` 这类字段做了脱敏，
**但不是每一行都过脱敏** —— 带完整签名的直链仍可能出现在日志里。

所以：贴到 Issue 之前自己扫一遍，或者只发给信任的人。

## 官网站点

官网站点是纯静态页面，没有分析脚本、没有 Cookie、没有从第三方 CDN 拉来的资源。
里面的更新日志是发布数据，在更新网站时于本地抓取后写进文件，访客打开页面不会触发统计请求。
应用内匿名统计与官网站点分开，不会把网页访问和 App 安装标识关联起来。
