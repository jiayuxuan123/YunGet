社区

本项目没有聊天群，也没有评论系统。所有反馈都走仓库的 Issue —— 那里可搜索、可追溯，也不会因为某个群散掉而丢失。

问题反馈

一份能复现的报告胜过十条意见。有用的问题会写清：应用版本（设置页或关于页可见）、Android 版本与机型、出问题的网盘、复现步骤，以及导出的日志。

应用内「设置 → 导出日志」会导出崩溃日志与应用信息，直接附在 Issue 里即可。

提交 Issue导出日志说明

与上游的关系

本项目是 CYQawa/YunX（云析） 的二次开发版本，两者是各自独立的项目：

  • 代码在本仓库开源，遵循 AGPL-3.0，并保留上游的版权与协议声明；
  • 应用内的赞赏码只面向本二次开发版；想支持上游原作者请移步上游仓库 —— 两者互不相关，避免权益混淆；
  • 问题反馈请提到本仓库；上游仓库不受理本版本的问题。

署名要求见仓库的 NOTICE。
