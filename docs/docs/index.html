文档

从这里开始

第一次安装，按“项目说明 → 使用说明 → 常见问题”的顺序最快。

  • 项目说明它是什么、支持哪些网盘、能做什么、怎么从源码构建 —— 就是仓库里的那篇 README。README.md
  • 使用说明从粘贴一条分享链接开始：解析、浏览、取直链、下载，以及登录与凭证怎么处理。docs/GUIDE.md
  • 常见问题解析失败、速度慢、换机要重登、更新检不出来 —— 这些问题的成因与处理办法。docs/FAQ.md

理解下载实现

想从源码运行或排查下载问题，再看构建与引擎文档。

  • 从源码构建需要的 JDK 与 SDK、签名怎么配、测试怎么跑，以及国内网络环境下的仓库镜像。docs/BUILD.md
  • 下载引擎TurboDL 负责什么、应用里为什么不止一个引擎、什么时候会用到哪一个。docs/ENGINES.md

插件开发

Android 版只启用 JavaScript 插件。先读边界，再看 ABI 与发布流程。

  • 写一个插件插件是一段 JavaScript：能做什么、不能做什么，以及从零写一个能跑的解析器。docs/PLUGIN-DEV.md
  • 插件 ABI 参考脚本能用的每一样东西：plugin / host 两个对象、能力、错误码与所有上限。docs/PLUGIN-API.md
  • 打包与发布清单怎么写、签名怎么算、怎么提 PR 进官方源、怎么自建一个源、怎么发新版本。docs/PLUGIN-PUBLISH.md
  • 插件安全模型信任四级、校验链，以及这份机制不做（也不打算假装做了）的那些承诺。docs/PLUGIN-SECURITY.md

协议与说明

下载与使用前需要知道的版权、隐私和责任边界都保留在这里。

  • 开源协议（AGPL-3.0）本项目基于 GNU AGPL-3.0 开源，这里是协议原文，一字未改。LICENSE

  • 隐私说明网盘凭证存在哪、会发给谁，以及哪些数据从来不离开这台设备。docs/PRIVACY.md
  • 使用条款与免责声明使用者的责任、软件提供到什么程度、下载内容的版权归属。docs/TERMS.md
