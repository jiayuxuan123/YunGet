三分钟上手

  1. 从 下载页取当前版本的 APK；
  2. 允许「未知来源」安装（应用没有上架任何应用商店）；
  3. 在「网盘」页登录你要用的网盘 —— 不登录只能看到文件名，拿不到可下载的直链；
  4. 复制一条分享链接，切回应用，点提示里的「粘贴」，解析、浏览、选中要下的文件；
  5. 任务出现在「下载」页，可以暂停、继续、删除、打开。
shell
# 想自己编译一版：
git clone https://github.com/jiayuxuan123/YunGet.git
cd YunGet
./gradlew :app:assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk

技术栈

Kotlin · Jetpack Compose · Material 3 · Room · OkHttp · TurboDL · KSP

下载引擎与 HLS 都由 TurboDL 提供，所以引擎的改进可以单独升级、也可以被别的应用复用。应用自己负责的是网盘解析、文件浏览、任务管理与界面。
