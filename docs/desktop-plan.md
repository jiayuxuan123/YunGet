# Windows 桌面端：功能与界面规划

> 现状是骨架：能解析蓝奏（单文件/带提取码）、能下载、能改八项设置。
> 下面这份规划是把手机端的能力按**桌面习惯**重做一遍，而不是把手机界面照搬过来。

## 0. 目标

一份 Flutter 代码出 Windows（x64 / ARM64）客户端，能力对齐 Android 版，交互按桌面重做：
键盘优先、可多选、可拖放、可常驻托盘。手机端继续用现有 Compose 版本，等桌面端功能对齐后再决定是否迁移。

## 1. 设计语言（桌面优先，不是手机放大版）

- **布局**：左侧导航（解析 / 网盘 / 下载 / 设置）+ 主区。网盘与下载用「列表 + 右侧详情」，宽屏三栏。
- **密度**：列表行高 40px、正文 13–15px；圆角 8–10px。手机端那种大圆角、大留白在桌面上会显得空。
- **交互**：
  - `Ctrl+K` 命令面板（跳转、开始下载、暂停全部、打开目录）
  - 粘贴链接即解析；`Enter` 下载、`Space` 暂停/继续、`Delete` 删除
  - `Ctrl/Shift` 多选，右键菜单（下载/复制链接/打开目录/删除）
  - 文件拖进窗口 = 新建下载；任务行拖到资源管理器 = 复制文件
- **状态**：空态给示例链接、加载用骨架屏、错误可复制并带重试、离线提示网络不可达。
- **主题**：跟随系统 / 浅色 / 深色 + 主题色（沿用手机端的种子色）；支持 100%/125%/150% 缩放与「紧凑/标准」两档密度。
- **托盘**：最小化到托盘、图标进度环、右键菜单（暂停全部 / 继续全部 / 打开主窗口 / 退出）。
- **通知**：完成与失败的系统通知，可关；速度通知可选。

## 2. 信息架构

| 区块 | 内容 |
|---|---|
| 解析 | 输入区（链接 + 提取码）+ 结果列表（文件 / 视频卡片）+ 最近记录 |
| 网盘 | 账号栏（多平台）+ 文件浏览器（面包屑、多选、右键）+ 容量 |
| 下载 | 三个筛选（进行中 / 已完成 / 失败）+ 搜索 + 列表 + 详情面板 |
| 设置 | 下载 / 引擎 / 网络 / 外观 / 通知 / 高级 / 关于 |

## 3. 功能对齐：解析

- **分享链接**：蓝奏、蓝奏优享、夸克、UC、迅雷、百度、139、123、115、广雅、GitHub Release。
- 支持带/不带提取码、子目录、单选与批量下载、复制直链。
- **视频解析**：微博、AcFun、B 站、Pixiv（纯 HTTP，可移植）。
  抖音、快手依赖 WebView 取签名 —— 桌面端先标注「暂不支持」，M6 用内置 WebView2 解决。
- 收藏夹、解析历史、剪贴板监听（可关）。

## 4. 功能对齐：网盘

每个平台都要：登录、列目录、下载、批量、容量（能取到就显示）。

| 平台 | 登录方式 | 列表 | 下载 | 转存 |
|---|---|---|---|---|
| 蓝奏云 | 匿名分享（已完成）/ Cookie | ✅ | ✅ | — |
| 蓝奏优享 | 账号密码（appToken） | 待做 | 待做 | — |
| 夸克 | 扫码取 Cookie | 待做 | 待做 | ✅ |
| UC | 扫码取 Cookie | 待做 | 待做 | ✅ |
| 百度 | 扫码取 Cookie | 待做 | 待做 | ✅ |
| 139 | 账号密码 | 待做 | 待做 | ✅ |
| 123 | 账号密码 / API | 待做 | 待做 | ✅ |
| 115 | 扫码取 Cookie | 待做 | 待做 | ✅ |
| 广雅 | 账号密码 | 待做 | 待做 | ✅ |

## 5. 功能对齐：下载

- 列表：文件名、大小、进度、速度、连接数、来源、状态。
- 操作：暂停 / 继续 / 取消 / 重试 / 打开目录 / 复制链接 / 删除记录。
- 批量：全选、按状态筛选、批量暂停/继续/删除。
- 排序与搜索：时间 / 大小 / 名称，关键字过滤。
- 详情：分片数、探测结果（大小/Range/ETag）、续传判定说明（宿主已产出 resumeNote）。

## 6. 功能对齐：设置（逐项）

| 分组 | 项 |
|---|---|
| 下载 | 下载目录、单任务连接数、同时任务数、全局限速、失败重试次数、完成后动作（无/打开目录/打开文件） |
| 引擎 | 分片开关、每连接分片数、动态分片、收尾托管、自适应并发、背压阈值、单 host 连接上限、块大小、最小分片、分片总数上限、单分片最大拆分、连接/读/探测超时、探测重试、慢启动起点、UA、HTTP 版本策略、忽略证书、已知大小跳过探测、信任弱校验器 |
| 网络 | 代理（跟随系统 / 直连 / 手动）、DoH 地址 |
| 外观 | 主题模式、主题色、界面缩放、列表密度 |
| 通知 | 完成、失败、显示速度 |
| 高级 | 诊断模式、日志查看与导出、配置导入导出（= 手机端的备份恢复） |
| 关于 | 版本、检查更新、开源许可、免责声明 |

**手机端有、桌面端换成等价物的**：锁屏继续 → 「任务运行时阻止系统休眠」；电池优化/通知权限 → 安装与托盘引导；桌面图标切换 → 不做；APK 自更新 → 安装包/绿色版更新。

## 8. 里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| M3 | 网盘框架（账号 + 目录 + 下载）+ 蓝奏账号 + 夸克 + UC | 三个平台各能登录、列目录、下载并校验字节数 |
| M4 | 其余网盘 + 批量/转存 + 容量 | 每平台跑通一条真实分享；批量下载 10 个文件成功 |
| M5 | 设置全量 + 主题/外观 + 日志/备份 | 每个设置项改完即时生效；导出配置能再导入还原 |
| M6 | 视频解析 + 收藏 + 内置 WebView2 登录 | B 站/微博/AcFun 解析成功；抖音标记或不支持说明 |
| M7 | 托盘、通知、快捷键、命令面板、空态/错误态 | 全键盘可完成一次完整下载 |
| M8 | x64 / ARM64 打包 + 更新 | 两个包都能启动；ARM64 标注未实测 |

## 9. 风险与取舍

- **登录态**：桌面 Cookie 必须加密存储（DPAPI），不能明文放 JSON。
- **扫码登录**：需要 WebView2；若系统缺 WebView2，要给出降级（粘贴 Cookie）。
- **抖音/快手**：强依赖 WebView 的签名，桌面端排到 M6。
- **ARM64**：本机无法运行验证，只能保证结构与依赖正确。
- **协议一致性**：同一份消息格式 Android 与 Windows 共用，改一处必须两边回归。
- **视觉升级要成套**：先定设计 token（间距/圆角/字号/颜色/动效），再逐屏套用；否则每屏各写一套，最后还是要重做。
