# 云取链接助手（v2.0）

Manifest V3 浏览器扩展，配合「云取 Windows 桌面端（2.7.48+）」使用：

1. **自动拦截浏览器下载**：点击网页下载链接（如 GitHub Release、直链、网盘下载等）时自动检测本机云取桌面端，在线时自动附带浏览器 `Cookie / Referer / User-Agent` 交给云取满速下载，并取消浏览器重复下载；桌面端未运行时自动放行浏览器默认下载。
2. **网页媒体与文件资源嗅探**：实时捕获当前标签页加载的 `HLS (.m3u8)`、`DASH (.mpd)`、视频、音频和附件直链，图标角标显示捕获数量，点开即可一键交给云取 PC 下载（自动携带捕获的请求头与 Cookie）。
3. **右键菜单接管**：右键任意链接/视频/音频可选择「用云取 PC 直接下载」或「发送到云取 PC 解析」。

## 安装（开发者模式）

1. 解压 `yunget-link-relay.zip`。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选中解压目录（已装旧版则覆盖目录后点刷新图标即可）。
