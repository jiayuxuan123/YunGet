# 经典界面

此目录保留 `v2.7.26`（提交 `210e35eb`）的 Android UI 实现。
它与新版使用同一套 ViewModel、Room 数据库、SettingsRepository、下载管理器和插件运行时。
不复制引擎、账号仓库、网络 API 或后台服务。

- 四个主页面在创建新版页面状态之前分发到这里。
- 解析结果、视频解析结果与直链对话框也使用对应的经典布局。
- 静态调色板与字阶来自该 tag；用户选择的动态取色、自定义色和对比度继续生效。
- 主题页和支持页共用当前实现，因此经典模式也能切回新版，并使用双赞赏码等新功能。
- 经典下载的紧凑卡片保留旧控件；任务详情接入共用的详情面板，目录内任务同样可查看详情、安装或预览。
- “显示设置说明”只控制辅助解释，当前目录、并发上限等值仍保留。

维护要求：新增业务能力优先放在共用 ViewModel 或操作组件；两种呈现都必须接线。
截图预览必须调用这里的实际组件，不允许用新版组件配上经典主题冒充经典预览。
