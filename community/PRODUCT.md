# Product

## Platform

web，优先适配云取 Android 应用内 WebView，同时支持手机浏览器与桌面浏览器。

## Users

云取与 TurboDL 用户以反馈问题、提出建议、参与讨论和查看处理进度为主；闲聊是附加入口。开发者在 Cloudflare Access 验证后管理内容。

## Product Purpose

让用户在应用的「公告与社区」入口内看公告、发帖、评论、投票、收发处理通知和交流使用体验。

## Capabilities and Constraints

- 普通用户无需开发者登录；首次写入设置昵称并通过同域自托管 ALTCHA，后端分配公开 UID 和 HttpOnly 会话。
- 找回码可恢复同一 UID，不依赖手机号、邮箱或 Android 硬件标识。
- 验证过程只请求社区自己的脚本与接口，服务端校验、防重放和限流共同防止批量滥用。
- 公告、帖子、评论、投票、通知、反馈、回复和消息通过 Worker/D1 接口读取；旧 API 与数据库保留。
- 私密反馈仅作者与通过服务端验证的开发者可见。
- 帖子图片在浏览器压缩，服务端验证格式、归属和体积，不使用未启用的 R2。
- 云取 2.7.33 接入社区未读数和通知入口。
- 无实际连接的 Android 设备时，只记录浏览器与视口测试，不声称完成真机键盘验收。

## Product Principles

1. 首屏先展示社区内容，发帖和评论按需展开。
2. 信息流、评论、通知和旧反馈各有清楚入口，不把后台入口暴露给普通成员。
3. 刷新不丢编辑草稿；长评论按游标分页，不强制把阅读旧内容的用户拉到底部。
4. 默认跟随系统明暗，可手动切换，遵守减少动态效果设置。
5. 只让用户填写完成任务所需的信息，不展示技术实现细节。
