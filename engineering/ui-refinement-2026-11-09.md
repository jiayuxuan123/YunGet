# 云取 2.7.28 本地 UI 细化

## 本轮方向

用户取消只使用 Google MD 的限制，允许学习 Astryx 的经验，同时明确不要求复制整套外观。
本轮以云取常用操作、原生中文阅读与低渲染开销为目标；经典主页面继续使用已恢复的布局。
版本保持未发布的 `2.7.28` / `76`，官网、公告和线上发布暂不更新。

## 已落地

- 新版使用较柔和的云取蓝与灰白背景，深色使用分层炭灰和柔和蓝色前景。
- 设置行移除逐个蓝底图标块和分组外圈边框；保留分隔与触控反馈。
- 短当前值在空间足够时靠右显示，长值或大字号放在标题下方；开启说明后仍显示实际当前值。
- 设置开关行补充可供辅助功能读取的开关状态；原有点击与长按回调保留。
- 主题页由重复卡片改为章节、间距和细分隔，保留所有配色、对比度、动效、密度、文件名和图标选项。
- 主题和下载共用原生选择组件：完整圆角的选中块、短距离滑动、48dp 点击区域；空间不足时转为纵向选项。
- 下载批量操作收紧，暂停进度显示灰色，已完成和失败使用独立语义颜色，保留详情、预览、安装和删除入口。
- 颜色内容角色包含对比度保护；默认色选中操作恢复默认方案，避免预览勾选与实际色彩不一致。
- 设置预览补齐实际分组顺序和此前缺少的下载引擎、插件、限速等项，避免把简化预览误当成完整生产页面。

## 性能边界

继续使用现有 Compose 与系统字体，没有新增 UI 运行时或依赖。
选择动画只随选项改变运行；关闭动效使用现有偏好，下载进度仍在局部订阅与绘制。
本轮未测得真机帧率、内存或滚动性能，因此不声称性能提升的具体数字。
