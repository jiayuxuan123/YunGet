# 本轮交付：社区、通知与引擎稳定性

## 范围与版本

基线：云取 2.7.32 / 80、TurboDL 0.5.0.3。下一个候选为云取 2.7.33 / 81、TurboDL 0.5.0.4；不覆盖已有发行。

继续完成引擎稳定性修复，同时交付真正可用的社区。Windows 客户端保持暂停。UI 保留云取现有视觉基础，主界面只整理顶栏：收藏左移、右侧加入通知。

## 引擎已复现的缺陷

- HTML 429/503 在等待服务端 Retry-After 前进入 UA 协商，过早重发请求。
- 长等待的探测错误被当作网页响应，错误归因不准。
- 暂停阻塞中的探测后未及时中断网络，全局连接名额无法释放，拖住下一任务。
- 弱校验器续传的指纹请求同样未及时响应协程取消。

`ProbeStabilityTest` 初始四项均复现；指纹取消的第五项也已单独复现。修复后七套件 39 项受影响测试通过，包含 SHA-256、连接复用和旧断点保留。原生产代码以 0.5.0.3 为基线，当前修复尚未发布。

## 社区交付

1. 信息流：发帖、分类、公告置顶、点赞、自己的帖子删除，开发者管理隐藏与处理状态。
2. 评论：游标分页、回复目标、按需加载、有界 DOM；测试至少 5000 条数据，避免一次取回所有评论。
3. 图片：选图、浏览器压缩、预览、删除待上传图片、点击查看；服务端验证格式/大小，绑定上传者，禁止借用他人未发布图片。
4. 投票：2–6 个选项、截止日期、每 UID 一票、可在截止前更改；后台判定截止与权限，重复请求不重复计票。
5. 账号：自动分配随机公开 UID，自选昵称；HttpOnly Cookie 会话，找回码恢复，昵称和 UID 不能单独作为登录凭据。不使用 Android 硬件 ID。
6. 通知：社区回复与反馈状态通知，公开公告；未读计数、标为已读、正确跳转原帖。App 顶栏通知入口真实接入。
7. 兼容：旧反馈、私密反馈、评论、账号会话和开发者 Access 保留；旧作者内部 ID 保持不变，新增稳定 UID 关联。原接口保持可用。

## 身份与存储边界

- `community_accounts.id` 兼容旧作者的会话哈希，公开展示独立随机 UID；`sessions.account_id` 支持轮换会话与跨设备找回。
- 找回码只显示给已验证的本人，服务端仅保存摘要；普通用户登录与开发者管理权限完全分开。
- 开发者仍通过 Cloudflare Access，服务端验证 JWT，不信任客户端角色、昵称或 UID。
- 账号未启用 R2；本轮用现有 D1 有界图片存储，不启用新付费服务。图片在客户端压缩，服务端限制单张体积和总容量；不把二进制图片带进信息流查询。
- 读 API 分页有明确上限，私密内容按作者/开发者鉴权；用户内容按纯文本渲染。
- 使用原同域 ALTCHA、限流、Origin 检查、幂等键；不恢复第三方验证码。
- 原匿名统计不收集帖子正文、图片、昵称、UID、找回码、原始错误或私有链接。
