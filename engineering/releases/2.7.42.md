# 云取 2.7.42

Android 正式版（versionCode 92，内置 TurboDL 0.5.0.8）同步附带 **Windows x64 早期 Beta 安装包**。Android 端已安装旧版可直接覆盖升级，保留账号与任务数据。

## Windows 端（早期 Beta 版）

> **说明**：Windows 端当前为**早期 Beta 预览版**，先提供基于 Compose Desktop 与原生 TurboDL 引擎的完整安装器体验；应用内网页登录自动获取凭证、更多网盘（如迅雷/移动云盘/小飞机个人盘等）以及桌面端界面打磨将在后续版本持续补齐。

- 新增 Windows x64 `.msi` 安装包（`YunGet-2.7.42-windows-x64-beta.msi`），内置裁剪后的 JVM 运行时与 TurboDL 0.5.0.8 原生 DLL（HTTP/1.1/2/3、HLS/DASH、BitTorrent/磁力、Metalink），支持自定义安装目录与开始菜单/桌面快捷方式。
- 首批接入 10 大网盘分享解析、GitHub 仓库/发行版与镜像加速、8 个个人网盘目录管理（夸克、百度、UC、123、115、蓝奏优享、光鸭、蓝奏云）、多任务并发下载队列、限速、代理、DoH 及深浅主题切换。
- 用户数据独立存放在 `%APPDATA%\YunGet`，与安装目录和历史旧版桌面残留隔离，避免覆盖升级或旧数据导致启动异常。

## Android 端

- 将各网盘 API、分享解析仓储与上传签名逻辑抽离至共用 `:core` 模块，供 Android 与 Windows 端复用。
- 修复原生下载引擎在排队（`QUEUED`）和尚未有字节写入的探测阶段（`PROBING`）提前上报进度引起的界面状态抖动。
- 解耦蓝奏优享解析仓储对 Android 账号仓库的直接依赖。

## 验证

- `:core:test`、`:app:testDebugUnitTest`、`:desktopApp:test`（含配置持久化、旧格式容错、本地回环传输及 4 页面浅色/深色离屏渲染校验）全部通过。
- Android 四种发布 APK（universal / arm64-v8a / armeabi-v7a / x86_64）与 aria2 可选内核包均使用原发布签名并通过 `verifyApkVersion` 校验；Windows `.msi` 与打包可执行程序已完成启动验证。
