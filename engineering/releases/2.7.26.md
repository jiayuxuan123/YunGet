# YunGet 2.7.26

版本：2.7.26（versionCode 74）

## 修复

- 修复 aria2 可选内核下载仅依赖 GitHub API 与直链、任一路径失败即中止的问题。版本信息增加官网清单、仓库清单与随包保存的已发布版本作为备用来源。
- 内核文件依次尝试官方加速、设置中的 HTTPS 下载镜像和 GitHub 直连；失败时显示各通道原因。
- 下载后同时校验 SHA-256、包名、发布签名和 ARM64 二进制，拒绝不完整、内容异常或签名不一致的包。
- 增加内核下载取消操作，已校验的缓存安装包可直接复用。
- 首次需要授权安装应用时，提示授权后返回再次点击安装。

## 引擎与界面

- 内置 TurboDL 及其插件升级到 0.5.0.1，Android 继续使用 Kotlin/ART 下载路径。
- 合入 TurboDL 对 DoH 响应大小的限制，防止异常响应占用过多内存。
- 下载引擎页显示内置引擎版本，并接通「公告与社区」更新说明入口；关于页同步显示引擎版本。
- 更新下载引擎、分包与构建文档。

## 下载说明

不确定架构时安装 `0-YunGet-2.7.26-universal.apk`。另外提供 arm64-v8a、armeabi-v7a 和 x86_64 三种应用包，均可覆盖安装。

`YunGet-aria2-kernel-arm64-v8a.apk` 是独立可选内核，仅支持 ARM64，普通使用无需安装。已安装且可用的内核可以继续使用。所有 APK 的 SHA-256 见附件 `SHA256SUMS.txt`。

## 验证

- 应用：41 个套件、343 项单元测试，0 失败、0 跳过；共享 core：26 项测试通过。
- 12 项新增内核下载回归覆盖备用版本信息、通道切换、损坏/不完整文件、签名拒绝、取消及缓存复用。
- 新下载链路实际网络冒烟：完整下载 8,136,903 字节的已发布内核，耗时约 15.6 秒；SHA-256、ZIP 内 ARM64 二进制和发布签名均通过验证。
- 六个 TurboDL 模块的实际构建依赖均为 0.5.0.1。
- 四种应用 APK 均通过 `verifyApkVersion`（2.7.26 / 74）、签名与 ZIP 完整性检查；DEX 中包含新的内核下载实现与引擎版本入口，随包备用清单也已打入安装包。
- 官网 23 页审计无问题，1,032 条内部链接有效。

验证范围：本轮未连接 Android 真机，系统安装器交互和各 OEM 上的内核运行仍需设备验证。网络冒烟使用桌面 JVM 执行与应用相同的下载实现，未将其当作手机运行结果。
