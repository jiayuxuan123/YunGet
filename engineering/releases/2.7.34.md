# 云取 2.7.34

版本：`2.7.34`（versionCode `82`），内置 TurboDL `0.5.0.5`。本版修复下载失败时诊断信息丢失，并改善社区统计后台对旧事件的显示。

## 下载诊断

- 分片请求一旦开始接收响应，就标记为“传输”阶段；服务器如果在返回首字节前限流，不会再误标成“探测”。
- TurboDL 会保留最近一次真实 HTTP 错误码。限流失败显示具体的 `429` 或 `503`，授权/时效失败显示具体的 `401`、`403` 或 `410`。
- 应用即使没有完整的请求耗时指标，也会保留可用的 HTTP 状态和失败阶段，不再把整条诊断丢弃。
- 任务结束时清理状态缓存，避免长期运行时不断累积。

## 社区统计后台

- 新版本失败事件会显示真实 HTTP 状态和传输阶段。
- 旧版只保存“429/503”或“401/403/410”合并类别时，后台明确显示为“类别”，不再误写成“未上报”。
- “探测”阶段的显示文字改为“探测/首包”，便于区分元数据探测和传输请求在拿到首字节前失败。
- 不新增链接、文件名、账号、Cookie 或原始错误文本上报。

## 兼容与验证

- 内置引擎升级至 TurboDL `0.5.0.5`；Maven API、旧任务、断点和插件接口保持兼容。
- TurboDL 发布门禁：117个套件、635项测试、0失败、0跳过。
- 云取应用：66个套件、441项测试；应用 core：26项测试；均无失败和跳过。
- 社区后端与页面：35项测试通过；界面基准和浏览器检查通过。
- 云取执行四种 APK、版本、ZIP、ABI和签名检查。
- 本轮没有连接中的 Android 真机，不声明完成真机触控或帧率验收。
