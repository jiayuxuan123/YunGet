# 云取 2.7.47

Android 版本号为 97，内置 TurboDL 0.5.0.10。本次同步提供 Android APK 和 Windows x64 安装器。

## 修复打包

- 2.7.46 的 Android 安装包误用兼容源集构建，漏带 `libturbodl_engine.so`，导致 TurboDL 原生下载不可用、并发上限被限制为 256。
- 本版恢复原生引擎打包，四个 ABI 均包含 `libturbodl_engine.so`；线程上限重新开放到 512，512 档继续只作用于 TurboDL 原生 HTTP 下载。

## 下载

- 从解析页、网盘或更新包发起下载后，「下载」页会切回「正在下载」，不再停留在上次查看的「已完成」；在下载页内新增任务、磁力任务和外部网盘回传的下载使用同一套切页逻辑。

## 网盘与账号

- 百度分享的子目录浏览与转存改用本次分享的 `BDCLND`，不再沿用登录 Cookie 中残留的旧分享标识，避免 errno=2；错误提示补充 9013 风控、-6 登录失效、31066 失效等常见原因。
- 认证备份导入的账号会恢复为主账号，避免恢复后仍然提示未登录。
- 迅雷旧备份缺少登录方式时，刷新失败会自动改用网页版 OAuth 客户端重试，并把新凭证写回原账号；并发请求复用同一次刷新结果，不再把旧 token 误报为过期。
- 网页网盘统一 WebView 配置，新增桌面版/移动版切换和「回到网盘首页」，显示加载进度；http 页面自动升级 https，非 http(s) 跳转被拦截；返回键先回退网页；修正微云登录弹窗的回调与会话写回。

## 验证范围

Android 通过 474 项应用单元测试和 50 项核心测试。四种 APK 均通过 `verifyApkVersion`、ZIP 完整性、原生库 ABIs 和原发布签名校验。网页网盘的显示与登录跳转仍需在真实网盘账号和 Android 设备上复测。

## 安装包

- Android 提供 ARM64、ARMv7、x86_64 和通用 APK，继续使用原正式版签名。
- Windows 提供 x64 MSI。可选的 Android ARM64 aria2 内核作为独立附件提供。
- 安装包校验值见 `SHA256SUMS.txt`。
