# 云取 2.7.33

版本：`2.7.33`（versionCode `81`），内置 TurboDL `0.5.0.4`。本版相对 `2.7.32` 更新社区、通知、启动图标和下载引擎的限流恢复。

## 社区与通知

- 「公告与社区」升级为可直接使用的社区。普通用户设置昵称后获得独立公开 UID，可发布帖子、评论、回复、点赞和参与投票。
- 帖子最多添加 4 张图片，图片在浏览器内压缩后上传；投票支持 2–6 个选项，每名用户只能投一票，并可在截止前更改。
- 信息流支持讨论、提问、建议、问题四类内容；长评论按游标分批加载，不会一次拉取全部记录。
- 社区回复、反馈处理进度和公告会进入通知列表。主界面收藏按钮左移，原位置改为独立通知入口，并显示未读数量。
- 开发者后台增加手机可用的顶部入口：社区与帖子、匿名统计、旧闲聊和公开社区，不再依赖桌面侧栏。
- 「我的」页面增加旧闲聊入口，手机端可直接进入原有聊天窗口。
- 社区身份与网盘账号完全分开。昵称可重复，公开 UID 不用于登录；换设备时可使用一次性展示的找回码恢复同一身份。
- 普通成员不显示开发者后台和匿名统计入口；开发者后台仍由 Cloudflare Access 管理。
- 匿名统计不采集帖子正文、评论、图片、昵称、公开 UID、找回码或私有链接。

## 社区修复

- 修复提交帖子时预览文字为空导致无法发布的问题。
- 修复应用通知角标读取的 Cookie 名称不一致，导致已登录但角标始终为 0 的问题。
- 修复普通成员也能看到开发者后台和匿名统计链接的问题。
- 修复手机端信息流、评论、通知和资料页的横向溢出，统一浅色、深色和桌面布局。
- 修复手机底栏五个入口的图标与文字错位，通知角标、发帖按钮和个人入口改为严格按列居中。
- 发帖或评论时选择图片后，即使 WebView 因系统选择器重新加载，当前页面、文字草稿和已上传图片也会恢复，不再关闭发帖页。
- 清理社区图片、验证组件和脚本的外部依赖；人机验证继续从社区同域加载。

## 启动图标

- 重新裁切自适应、圆形、单色和旧版启动图标，四边保留白色安全区。
- 修复云朵下方箭头在部分手机图标形状中被裁掉的问题。

## TurboDL 0.5.0.4

- 探测请求收到 HTTP 429 或 503 时，先遵守服务器返回的 `Retry-After`，不再把限流页误判为浏览器标识被拦截。
- 服务器要求长时间等待时停止本轮自动重试，保留已有断点并显示限流原因，不用连续请求绕过限制。
- 暂停、取消或关闭任务时，正在等待响应的探测与续传校验请求会及时中断，尽快释放连接名额。
- 取消一个等待中的任务后，其他下载可以继续获得连接预算，不再被旧请求长时间占用。
- 正常完成且可复用的连接不会被取消逻辑误伤。

- 四种应用安装包继续提供通用、arm64-v8a、armeabi-v7a 和 x86_64 版本；aria2 可选内核沿用上一版已校验产物。
- 社区生产数据库已先备份，再执行加法迁移；旧反馈、回复、闲聊和会话继续保留。
- TurboDL 发布门禁：116个套件、634项测试、0失败、0跳过。
- 云取应用单测：66个套件、441项测试、0失败、0跳过；应用 core 单测26项通过。
- 社区后端34项测试、24项真实浏览器链路检查通过，桌面和390px手机无横向溢出。
- 四种 APK继续执行版本、ZIP、ABI和签名检查。本轮没有连接中的 Android 真机，不声称完成真机触控或帧率验收。
