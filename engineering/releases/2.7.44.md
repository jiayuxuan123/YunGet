# 云取 2.7.44

Android 正式版与 Windows x64 安装器同步更新，内置 TurboDL 0.5.0.9。Android 版本号为 94，沿用此前的发布签名，支持从正式版原地升级。

## Windows

- 在「我的网盘」新增城通网盘、阿里云盘、天翼云盘、腾讯微云、联通沃盘和 PikPak。每个平台使用独立的 Edge 或 Chrome 会话，可以在官网登录、浏览和下载文件，也可以在关闭该平台的浏览器窗口后退出本机会话。
- 支持按名称搜索网盘、复制官网地址和打开分享链接。智能解析可引导到网页版分享页，城通已经支持的公开分享继续走内置解析。
- 云取下载队列的单任务 HTTP 连接上限从 64 升至 512。「设置 → TurboDL 下载引擎」新增 128、256 和 512 快捷档。实际并发取决于文件大小、服务器 Range 支持和当前连接预算。

## Android

- 修正上述六个网页登录入口的 WebView 新窗口跳转，增加加载失败后重试、重新加载和用浏览器打开的入口。系统 WebView 支持按站点清理时，可以直接退出该网盘的应用内网页会话。
- 经典与现代样式共用这批网盘入口。经典样式也能打开小飞机网盘，并在下载确认窗口直接点击「复制链接」。
- 修复部分旧版数据库升级时，迅雷账号表缺少登录方式字段导致的启动崩溃。升级时保留现有账号内容和登录方式。
- TurboDL 原生 HTTP 下载新增 512 并发档。兼容下载路径的上限为 256。

## 跨端

- 文件列表显示网盘返回的文件时间，兼容 Unix 秒、毫秒和网盘已格式化的日期。

## 安装包

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `YunGet-2.7.44-windows-x64.msi` |
| Android ARM64 | `YunGet-2.7.44-arm64-v8a.apk` |
| Android ARMv7 | `YunGet-2.7.44-armeabi-v7a.apk` |
| Android x86-64 | `YunGet-2.7.44-x86_64.apk` |
| Android 通用 | `YunGet-2.7.44-universal.apk` |
| Android ARM64 可选 aria2 内核 | `YunGet-aria2-kernel-arm64-v8a.apk` |

手机不确定架构时可选通用包。已安装且可用的 aria2 内核可以继续使用。各附件的 SHA-256 见 `SHA256SUMS.txt`。

Windows 下载队列已用本地 Range 服务验证 512 条并发连接，并校验了下载文件的 SHA-256。六个官网登录入口已检查，真实账号登录后的操作取决于网盘服务和 WebView 环境。
