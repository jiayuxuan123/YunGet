# YunGet 2.7.28

版本：`2.7.28`（versionCode `76`）。以下为相对 `v2.7.27` 的完整更新。

## 修复

- 修复经典界面只切换顶栏与字阶、主页面仍使用新版布局的问题。经典模式恢复 `v2.7.26` 的解析输入、网盘账号卡片、下载单列表、设置逐行卡片，以及分享和视频解析结果布局。
- 经典配色与字阶恢复到对应版本；动态取色、自定义色、深浅色与对比度偏好继续有效。
- 两种界面共用账号和任务数据，切换界面无需迁移数据或重建下载引擎。
- 经典下载页补接当前的任务详情面板，保留安装、媒体预览和目录内任务操作。

## 外观与使用

- 设置首页和主题页增加“显示设置说明”开关，默认简洁显示。关闭时隐藏解释文字，当前目录、任务数、连接上限、限速、重试次数、DNS 与插件数量仍可查看。
- 新版设置行恢复紧凑的横向排版，说明与标题对齐；大字体可换行，开关保持可见。
- 新版下载页压缩顶部概览，保留全部暂停、全部开始和删除确认，把更多首屏空间留给任务。
- 主题页缩小配色预览，将新旧界面选择前置；动效使用增强、标准、关闭三档分段选择。
- 新版视觉学习 Astryx 的语义分层，使用更柔和的云取蓝与灰白底色；深色分别处理文字、按钮、状态标签的对比度。
- 设置行移除重复图标底板和外圈边框；短当前值靠右显示，长值或大字号换到标题下方，开启解释后仍保留当前值。
- 主题页使用章节与分隔线组织选项；滑动选中块统一圆角与动效，空间不足时使用纵向选择，保持 48dp 点击范围。
- 下载页批量操作更紧凑，任务独立分组；暂停使用灰色进度条，完成与失败使用各自语义颜色。
- 参考 Astryx 的分组与控件交互规则，合并重复容器；外观开关支持点击整行，保持原生控件及完整触控范围。

## 社区与反馈

- 「公告与社区」接入 Cloudflare 社区，软件内可查看公告、提交问题与建议、查看开发者回复，并可直接进入社区页面。
- 普通反馈不再要求开发者登录。未设置社区昵称时，表单仍可正常填写；提交时会引导设置昵称并完成人机验证，已填内容不会丢失。
- 开发者后台继续由 Cloudflare Access 保护，仅用于处理反馈和管理公告，与普通用户提交反馈分离。
- 社区页面提供浅色、深色和窄屏布局，反馈默认公开；涉及账号或敏感信息时可选择仅本人和管理员可见。

## 验证

- 发布前全量单元测试：应用 47 个套件、365 项测试，共享 core 26 项测试，均为 0 失败、0 错误、0 跳过；24 个 Compose 预览的截图回归通过。
- 社区 Worker 7 项测试通过；公网访客流程已验证表单可填写、提交时弹出昵称设置且原输入保持不变。
- 四种应用 APK 与可选 aria2 内核包完成构建；应用包通过版本校验，发布附件提供 SHA-256。
- 本轮未连接真实 Android 设备，触控路径、TalkBack 和真机帧率不在本轮验证范围内。

## 安装与兼容

- 四种应用 APK 均可覆盖安装。无法确定架构时选择文件名以 `0-YunGet` 开头的 universal 通用包。
- 账号、任务、保存目录与引擎设置沿用原数据；内置 TurboDL 保持 `0.5.0.1`。
- aria2 为独立可选 ARM64 内核，已经安装且可用时无需重复安装。
