# 云取 2.7.45

Android 版本号为 95，内置 TurboDL 0.5.0.10。本次同步提供 Android APK 和 Windows x64 安装器。

## 下载

- 调整最后一段 Range 的调度。有空闲连接且预估能缩短尾段时间时，内置引擎会安排分担，并保留暂停续传所需的分片记录。
- 新配置默认关闭吞吐自适应，原有设置会继续生效。开启时按整个采样窗口判断并发档位，减少错误降档。
- 内置下载遇到同批 HTTP 429 或 503 时合并计入重试预算。迅雷下载最多使用八条连接，Android 的重复限流会逐步延长冷却并降低恢复并发，已下载的分片可以续传。
- 修复 512 连接任务恢复时的策略读取。下载列表优先使用引擎实际回传的活动数。

## 网盘与社区

- 迅雷登录刷新区分网页版和 App 登录，并把新凭证写回发起请求的原账号。认证备份保留迅雷登录方式。
- 百度个人盘在打开时才加载目录，网盘页的例行加载会跳过百度配额。主动刷新可查看配额。
- UC 个人盘取链补齐客户端参数，取链过程接收更新后的会话 Cookie。
- Android 微云使用独立网页登录弹窗，天翼等官网可按屏幕宽度缩放。社区选图支持多张图片，回到社区时会恢复选图前的页面地址。

## WebDAV 加密备份

Android 和 Windows 都可从设置打开「WebDAV 加密备份」。两端填写同一个 HTTPS 备份文件地址，手动上传或读取并确认恢复。备份包含支持平台的主账号，以及每任务连接上限和同时下载任务数。数据在本机加密，既有备份文件须通过备用口令和版本校验方可更新。

## 验证范围

云取通过 48 项核心测试、467 项 Android 单元测试和 21 项桌面测试。社区代码检查及 35 项测试通过。TurboDL 的 Windows 原生门禁 106 项通过，四种 Android 原生库通过 16 KiB ELF 对齐检查。本地限速夹具中，文件完成时间中位数从 6.33 秒降到 5.62 秒，文件校验一致。微云实际登录、网盘下载速度和选图交互仍需在真实账号和 Android 设备上复测。

电脑端登录码若要求官方手机 App 确认，仍使用网盘提供的扫码入口。WebDAV 已验证加解密和地址校验，真实服务器的上传及还原流程待复测。

## 安装包

- Android 提供 ARM64、ARMv7、x86_64 和通用 APK，继续使用原正式版签名。
- Windows 提供 x64 MSI。可选的 Android ARM64 aria2 内核作为独立附件提供。
- 安装包校验值见 `SHA256SUMS.txt`。
