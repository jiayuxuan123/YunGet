# 云取 2.7.32

本版在 2.7.31 的基础上修复解析请求和匿名统计中的问题，内置 TurboDL 保持 0.5.0.3。

## 解析与保存

- 开始新解析或返回输入页时取消上一轮解析，减少旧请求覆盖新页面的情况。
- 解析过程中主动取消的请求不再按普通解析失败处理。
- 保存文件时区分存储权限失效和空间不足，分别提示重新选择目录或释放空间；有效缓存继续保留，可重试保存。

## 可选内核管理

- 下载引擎页增加 aria2 快捷卸载与安装包清理，卸载需要在系统界面确认。
- Gopeed 移除内核时一并清理临时安装包；下载任务、断点和个人文件保留。
- 相关任务仍在下载或等待执行、内核仍在安装时会阻止移除。可选内核可在之后重新下载安装。

## 匿名统计修复

- 修复不足一批的事件可能长时间未发送的问题；剩余事件会继续发送。
- 修复发送前删除本地记录导致断网或进程退出时丢失事件的问题，改为收到服务端确认后再删除，重传沿用原事件标识。
- 关闭统计时取消在途请求并清空待发送记录；旧的异步任务不能把记录重新写回。
- 区分首次开始和恢复下载；保存失败、处理失败和主动取消分别记录，避免重复算作网络下载失败。
- 修复字节数中的数字被识别为 HTTP 状态码、TLS 握手错误被归为文件校验失败的问题。
- 补齐解析失败的来源类别；可取得时记录任务阶段与最近 HTTP 错误码。大小和耗时继续使用区间，不上传链接、文件名、账号或原始错误消息。

## 开发者统计后台

- 取消“完成数除以开始数”的成功率展示，改为明确展示完成和失败的上报结果数；暂停、恢复和未完成任务不再被误解为失败。
- 每种失败同时显示发生次数、影响的匿名安装数、来源和阶段，并纳入解析失败与保存/处理失败。
- 版本和引擎分布按匿名安装数显示，避免把事件次数当成安装数。
- 日期范围和每日图统一使用北京时间，补齐没有事件的日期。
- 增加版本筛选；快速切换筛选时取消旧请求，避免晚到数据覆盖当前选择。
- 对旧版缺失的来源、阶段和错误码明确标注“未知/未上报”，保留原始统计，不推测填充。

匿名统计仍需用户同意，可随时在设置中关闭。本版不宣称已修复所有网盘的限流、认证或外部接口问题，旧版分类记录不足以确定这些问题的具体根因。

## 验证与兼容

- 应用单测 65 个套件、439 项通过，应用 core 单测 26 项通过；界面截图验证通过。
- 四种应用安装包继续支持 Android 7.0 及以上，可覆盖安装并保留现有账号与任务。
- 可选 aria2 内核沿用已发布且校验一致的版本，本次未改动内核二进制。
- 本轮没有连接中的 Android 真机，系统卸载确认与真实设备触控尚未进行实机验证。
