# 云取 2.7.41

Android 正式版，versionCode 91，内置 TurboDL 0.5.0.8。已安装 2.7.40 或 2.7.41-rc1 均可覆盖升级。

## 下载引擎

- 修复高并发下载时，单个请求预留的写盘缓冲过大，导致大文件只能跑到约 32 路的问题。现在按连接配置分配缓冲，仍受全局内存预算约束。
- 网络断流后，仅失败分片等待重试，其余分片继续下载。服务端限流仍遵守冷却时间。
- 修复部分双栈网络下，先遇到被拦截的 IPv6 地址后，可用的 IPv4 请求也被误判失败的问题。GitHub Release 等直链和远程种子文件共用这条修复路径。

## 设置

- 新版与经典设置均可打开「引擎高级参数」。返回后保留设置列表的滚动位置。
- 经典设置的「下载引擎」入口使用同样的独立页面切换方式。

## 验证

- 本地用同一 80 MiB 文件与 32 MiB 缓冲预算复测，峰值活动请求从 32 路升到 64 路，SHA-256 一致。
- 原生门禁共 98 项集成测试和 2 项组件测试通过。四种应用 APK 使用原发布签名，内置的 Android 原生库通过 16 KiB 对齐检查。
- 实际网盘稳态速度和手机触控仍待真机复测。
