# 云取 2.7.38

版本：`2.7.38`（versionCode `86`），内置 TurboDL `0.5.0.6`。

本版针对匿名统计暴露出的重复上报、错误归因和来源限流扩散问题进行修复。

## 统计准确性

- 同一安装在一分钟内产生、事件名与属性都相同的匿名事件会合并为一条计数，不再堆积数百条重复记录。
- 合并事件保留真实发生次数，后台的下载结果、失败次数和来源统计按发生次数计算，安装数仍按匿名安装标识去重。
- 同一任务在同一次尝试中从失败切回下载、再次失败时，只记录一次终态，避免重试界面状态造成重复失败。
- 直链和 GitHub 的 403 归类为 `HTTP 403`；夸克、百度、迅雷等登录型平台仍保留“认证或权限”分类。

## 限流保护

- 429/503 冷却不再只作用于单个任务；同一网盘来源的其他任务也会在冷却期内停止自动重试。
- 冷却期间继续点击其他同源任务会显示可重试时间，并保留断点。
- 不同来源和普通直链互不共享来源冷却，避免误伤。

## 验证

- 应用：69 个测试套件、449 项测试、0 失败、0 跳过。
- 应用 core：26 项测试、0 失败、0 跳过。
- 社区 38 项测试通过，覆盖事件合并计数与 HTTP 403 分类。
- 本轮没有连接中的 Android 真机，不声明真机验收。
