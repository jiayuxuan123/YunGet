# 云取 2.7.43

Android 正式版（versionCode 93，内置 TurboDL 0.5.0.9）与 **Windows x64 桌面端完整版安装包** 同步发布。Android 端已安装旧版可直接覆盖升级，保留账号与任务数据。

## Windows 桌面端重大升级

- **网页登录与凭据安全**：新增基于本机 Edge/Chrome 隔离会话 + 本地 CDP 的一键网页登录与自动抓凭证（覆盖夸克、百度、UC、迅雷、139、123、115、蓝奏云、B 站、小红书、Pixiv），补齐光鸭/蓝奏/小飞机账密及光鸭/迅雷短信直登；接入 Windows DPAPI（`Crypt32Util`）对账号凭据按当前用户加密落盘并自动迁移旧版明文；内置无头 Edge 页面抽取，补齐抖音/快手/小红书桌面视频解析。
- **网盘业务闭环**：支持同平台多账号管理、备注编辑与一键切换主账号；补齐夸克/UC/百度/139/123/115/光鸭/蓝奏优享/迅雷 9 大平台的分享转存（支持浏览目录与现场新建文件夹）、本地多文件上传（带进度与取消）和分享链接生成；启用小飞机个人盘浏览与直链下载。
- **桌面原生体验**：新增系统托盘与关闭最小化到托盘、任务完成/失败 Windows 原生通知、剪贴板监听快捷解析条、解析历史与收藏夹持久化、窗口文件/链接拖放、全列表右键菜单、`Ctrl+K` 命令面板及全局快捷键。
- **运维诊断与速率曲线**：新增实时日志查看器（桥接 `CoreLog` 并落盘 `yunget-desktop.log`）、配置 JSON 备份导入/导出（默认剔除账号与 SFTP 私钥密码）、GitHub Releases 检查更新与直链下载 MSI、任务详情实时速率曲线图。

## Android 端与跨端核心

- 内置引擎升级至 **TurboDL 0.5.0.9**：修复单源无强 ETag 的会话内分段并发、停滞分片主动回收（与全局限速协同避免误杀）及 SDK 续传恢复瞬间的测速基线虚高。
- 将中国移动云盘 139、迅雷与全平台视频解析核心抽离至共用 `:core` 模块，Android 与 Windows 端共享同一套协议实现；完善 Metalink 与 SFTP 原生路由能力检测与下载引擎设置联动。

## 验证

- `:core:test`（45/45）、`:app:testDebugUnitTest`、`:desktopApp:test`（18/18，含 DPAPI 加解密与明文迁移、无头 Edge CDP 页面抽取、多账号/历史/配置备份/日志与版本比较）全部通过。
- Android 四种发布 APK（universal / arm64-v8a / armeabi-v7a / x86_64）均通过 `verifyApkVersion`（versionCode 93 / versionName 2.7.43）与原发布签名校验；Windows `.msi`（`YunGet-2.7.43-windows-x64.msi`）内置 TurboDL 0.5.0.9 DLL 并完成隔离环境实测启动验证。
