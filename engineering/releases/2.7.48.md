# 云取 2.7.48

Android 版本号为 98，内置 TurboDL 0.5.0.10。本次同步提供 Android 四架构正式版 APK、Windows x64 安装包（MSI）及新版浏览器扩展「云取链接助手」v1.1。

## 分网盘安全并发与快捷调节（Android + Windows）

- **默认安全兜底与全局 512 解耦**：普通直链与 GitHub 仍放行至最高 512 线程；已知网盘默认套用推荐安全上限（迅雷 8、百度/UC/115 16、123/139/光鸭/蓝奏/小飞机/城通 32、夸克 64），强风控源连续遇 429/503 自动减半退让；PC 端同步向 TurboDL 原生核心透传按来源隔离的 `cooldownGroup`。
- **仅作默认值，完全可调**：双端更新后首次打开弹出策略说明，并内置「分网盘并发快捷调节」界面（入口位于下载页顶栏、设置页线程选项及说明弹窗），可按单个网盘自定义调高至最高 512、设为跟随全局或一键关闭兜底，并支持跨端 WebDAV 同步。

## 五网盘大文件过期自动换链（Android + Windows）

- 夸克（分享与个人盘）、UC、迅雷、123、139 个人盘下载大文件时，若直链中途过期返回 HTTP 401/403/410，Android 与 Windows 均会自动重新取链、校验预期文件大小并从原有断点无缝续传（单轮最多自动换链 2 次）。

## 跨端 WebDAV 加密同步升级

- 保持 v1 备份格式向前兼容，扩展支持同步**全部副账号（多账号）**、**收藏夹链接**（Android 收藏 ↔ PC 收藏去重合并）以及**全局限速、HTTP 策略与分网盘并发设置**。
- 弹窗记住上次填写的非敏感 WebDAV 文件地址与用户名（不保存密码和备份口令），解密后预览账号与收藏数量再确认恢复。

## Windows 桌面端实用升级

- **浏览器扩展接管与局域网推送接收**：内置本地链接接收服务（默认监听 `127.0.0.1:17890`），配合同步更新的「云取链接助手」v1.1 支持弹窗一键发送到云取 PC 与右键菜单接管；在设置开启「允许局域网手机推送」并核对配对令牌后，可接收手机端云取推送的下载任务。
- **挂机防休眠与完成后动作**：下载进行中自动阻止 Windows 进入睡眠（不影响熄屏）；全部任务完成后支持选择「无操作 / 打开下载目录 / 60 秒后自动关机（可随时取消）」。
- **同步账号修复**：补齐迅雷刷新并发去重与旧备份缺登录方式回退网页 OAuth 客户端修复。

## Android 端实用加固

- **下载前剩余空间预检**：开始下载前检查可用存储空间（预留 32 MiB 安全余量），明显放不下时提前提示，避免下到 99% 落盘失败。
- **切网自动重连**：监听网络恢复与 Wi-Fi/蜂窝切换，仅对瞬时网络中断失败的任务延迟 1.5 秒自动续传，不影响用户手动暂停或限流冷却任务。
- **带请求头直链导出与推电脑**：新版与经典直链弹窗均支持一键复制带 `User-Agent / Referer / Cookie` 的 `curl` 与 `aria2c` 命令，以及一键将大文件连同请求头推送到局域网电脑端云取满速下载。

## 验证范围

通过 59 项核心测试、24 项 Windows 桌面测试与 478 项 Android 单元测试（共 561 项，0 失败 / 0 跳过）。四个 Android 正式版 APK 均通过 `verifyApkVersion`（含 `libturbodl_engine.so` ABI 校验）、ZIP 完整性和原正式版签名校验；Windows x64 MSI 与远端附件均核对 SHA-256。真实手机切网恢复、真机向 PC 局域网推任务、真实 WebDAV 服务器上传/恢复及 Windows 实机倒计时关机待实机复测。

## 安装包

- Android 提供 ARM64、ARMv7、x86_64 和通用 APK，继续使用原正式版签名。
- Windows 提供 x64 MSI。可选的 Android ARM64 aria2 内核作为独立附件提供。
- 浏览器扩展「云取链接助手」v1.1 可在官网下载页获取。
- 各附件校验值见 `SHA256SUMS.txt`。
