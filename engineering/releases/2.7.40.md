# 云取 2.7.40

版本：`2.7.40`（versionCode `89`），内置 TurboDL `0.5.0.7`。

本版重点是 TurboDL 从 Kotlin/JVM 传输实现升级到 C++20 共用核心。原有 TurboDL 条目直接使用新核心。旧任务继续按原断点格式恢复，兼容引擎、aria2 可选内核和 Gopeed 可以继续选择。

## 原生核心替换

- 新增 C++20 共用下载核心，Android 通过 JNI 接收任务、返回进度和读取诊断信息。
- 网络请求由 libcurl multi 统一驱动，不再为每个分片单独启动一套阻塞请求；探测、分片、镜像和重试共用同一个事件循环。
- 断点由 SQLite 保存，记录目标文件、来源身份、已完成区间和每个数据块的摘要。只有文件数据和记录都同步完成后，才会提交对应断点。
- Android 原生构建链接 libtorrent 和 FFmpeg，分别负责 BT/磁力及 HLS/DASH 下载和合成。
- 原生核心通过版本化 C ABI 暴露能力，JNI 只传递批量状态和事件，不把每个下载字节都跨语言回调。
- Kotlin 插件协议与旧任务恢复路径继续由兼容层承载。

## 调度、并发和恢复

- 连接数、任务名额、缓冲区和全局限速由同一个资源域管理，避免多个任务各自计算上限后把进程资源吃满。
- 分片大小根据剩余区间、连接数、实测吞吐和启动成本动态调整；慢连接不会一直占着大段不完成的工作。
- 慢尾协助只在同一来源、身份可核对的条件下启用，镜像来源不能拿另一个来源的速度直接判断。
- 服务器返回 429/503 时统一处理冷却和 `Retry-After`，其他来源仍可继续工作；授权过期不会被当成服务器限速。
- 支持暂停、取消、进程结束后重新打开和强杀恢复。恢复前核对来源、文件长度和校验信息，确认旧数据仍属于当前任务后才继续。
- 下载前核对目标文件和断点的归属，已有文件保留在原位置。保存时遇到同名文件由云取选择可用文件名。

## 网络与协议

- 原生路径支持带请求头的 HTTP/HTTPS、FTP、Range、重定向、代理、系统证书、DoH、连接超时和限速。
- 核心镜像接口保留每个来源的独立请求头。并行混合下载需要独立的 SHA-256 作为内容一致性依据。
- 原生 curl 的协议列表按当前安装包实际编译能力生成。Android 构建没有 SFTP 时，不会因为把 `sftp` 写进协议列表而导致全部 HTTP 任务返回 `Unsupported HTTP option`。
- Android 原生传输依赖已编入 HTTP/2、HTTP/3 和 SFTP。下载引擎高级参数提供自动、HTTP/1.1、HTTP/2、HTTP/3 四种选择。选择 HTTP/3 时优先走 QUIC，任务详情显示实际协商出的协议。
- SFTP 的账号、SSH 密钥和服务器主机校验已接入 SDK 与 Windows CLI。云取客户端的 SFTP 凭据入口仍待接入。

## HLS、DASH 和 BT

- HLS/DASH 支持清单解析、音视频轨选择、初始化片段、ByteRange、AES-128、分片下载、MP4 合成和直播结束保存。
- 原生核心会保存已经验证的分片和处理阶段，重新打开后从断点继续；保存失败时可以只重试保存，不需要重新下载。
- BT/磁力使用 libtorrent。云取磁力和远程 `.torrent` 文件接到原生任务，种子下载完成后再进入 BT 队列。SDK 支持 Tracker/DHT、文件选择、暂停恢复和坏块重检。
- 多文件 BT 任务以完整目录作为产物，保存时保留目录结构；单文件种子按普通文件保存。
- 直播任务在任务详情页可以手动“结束录制并保存”，不再只能等清单自然结束。

## 下载过程与诊断

- 记录 DNS、连接、TLS、首字节、传输、校验、处理和保存阶段，任务失败时可以区分取链慢、连接慢、服务器限速、存储失败和完整性失败。
- 原生任务遇到异常时保留具体原因，不再把所有问题都显示成同一句 `Storage operation failed`。
- 下载前会检查目标目录是否可写；保存阶段失败会保留缓存，提示重新选择目录或释放空间。
- 任务详情、实时连接数和结果统计继续使用原有界面接口；原生状态通过 JNI 批量同步，不改变旧事件类型。

## 其它更新

- 更新亮色、暗色、标题字阶、圆角和导航选中状态。解析页缩短操作区，网盘页压缩排序和过滤区，设置首页可以直接打开当前引擎。
- 下载卡片按状态突出暂停、继续、重试、预览或安装，详情保留独立入口，删除移入更多菜单。批量控制与清理放在队列顶部。
- 将 Compose 导航、配色、字阶、链接输入、设置分组和 HTTP 策略抽到共用界面源码。平板使用侧栏，窄窗口使用底栏。
- 社区旧统计入口已停写 D1。旧客户端收到确认后会停止重试。
- 匿名统计接口迁移至 Google Analytics Measurement Protocol。本次发行包尚无统计配置，统计发送处于暂停状态。

## 验证范围

- 已在连接的 ARM64 Android 设备上安装测试包，原先失败的四个下载任务重试后全部完成，文件已写入公共下载目录；其中包含从网络下载的 APK 和带 UUID 文件名的链接。
- ARM64、ARMv7、x86_64 和 x86 原生库均通过 16 KiB ELF 检查。三个分架构 APK 和通用 APK 已完成签名、ZIP 及内置引擎摘要检查。
- TurboDL 的 Windows x64 CLI 已通过 HTTP/2 和 HTTP/3 文件传输校验。本次云取构建发布安卓版。
- Android 新构建仍需真机验证。Metalink、SFTP 凭据、复杂媒体路径及长时稳定性仍是正式版验收项。
